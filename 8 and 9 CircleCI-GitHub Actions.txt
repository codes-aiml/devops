Step 3: test_calculator.py
import unittestfrom calculator import add, multiplyclass TestCalculator(unittest.TestCase):    def test_add(self):        self.assertEqual(add(15, 25), 40)    def test_multiply(self):        self.assertEqual(multiply(4, 6), 24)    def test_negative(self):        self.assertEqual(add(-5, 10), 5)if __name__ == "__main__":    unittest.main()



Step 4: .github/workflows/python-app.yml
name: Python CI Pipeline

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.11'
      - run: python calculator.py
      - run: python -m unittest test_calculator.py


Step 5: Run locally
python calculator.py
python -m unittest test_calculator.py
